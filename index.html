🕐 timestamp_zone

浏览器原生的 Unix 时间戳 ↔ ISO 8601 ↔ 多时区转换工具。
所有计算在 WASM 中完成，隐私优先。

⚡ WASM 原生 🔒 零网络请求 🌍 16 个常用时区 📋 一键复制
🚀 打开转换器
🔢

Unix → 多格式

输入秒或毫秒，自动识别并转换为 ISO 8601、RFC 2822、RFC 3339 等标准格式。

📅

ISO 8601 → Unix

支持 RFC 3339、带时区偏移、纯日期时间、仅日期等多种 ISO 8601 格式。

🌍

多时区转换

内置 16 个常用时区，支持 UTC、美东、伦敦、上海、东京等，一键切换。

⏱️

时长计算

两个时间戳之间的精确时长，自动分解为天/时/分/秒，并生成人类可读字符串。

🔒

隐私优先

所有计算在浏览器 WASM 中完成，零网络请求，时间戳和时区查询绝不离开你的设备。

📋

一键复制

每个输出都配有复制按钮，一键复制到剪贴板，方便粘贴到日志、代码或聊天中。
