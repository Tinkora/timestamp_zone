# timestamp_zone 产品规格

## 产品一句话

浏览器原生的 Unix 时间戳 ↔ ISO 8601 ↔ 多时区转换工具。所有计算在 WASM 中完成，隐私优先。

## 目标用户

- 需要快速查看和转换 Unix 时间戳的开发者
- 跨时区团队协作者（查看日志、调试 API 响应时间）
- 需要将时间戳格式化为多种标准的运维人员
- 希望由 ChatGPT、Codex 或其他 Agent 自动完成时间转换的开发者

## 核心体验

1. 用户打开网页，无需任何网络请求即可使用
2. 点击"现在"按钮获取当前时间的所有格式输出
3. 输入 Unix 时间戳（秒或毫秒自动识别），查看 ISO 8601、RFC 2822、RFC 3339 和自定义格式
4. 输入 ISO 8601 字符串，转换为 Unix 时间戳
5. 选择目标时区，查看当地时间
6. 输入两个时间戳，计算时长
7. 每个输出旁边有复制按钮

## 功能清单

### Unix → 多格式转换
- 输入 Unix 秒或毫秒（自动识别：> 10000000000000 视为毫秒）
- 输出：ISO 8601、RFC 2822、RFC 3339、自定义 strftime 格式
- 自定义格式示例：`%Y-%m-%d %H:%M:%S`

### ISO 8601 → Unix
- 支持格式：`2026-08-06T16:30:00Z`、`2026-08-06T16:30:00+08:00`、`2026-08-06T16:30:00`、`2026-08-06`
- 输出：Unix 秒和毫秒

### 时区转换
- 内置 16 个常用时区：UTC、US Eastern/Pacific/Central/Mountain、Europe/London/Berlin/Paris、Asia/Shanghai/Tokyo/Seoul/Singapore/Kolkata、Australia/Sydney、Pacific/Auckland
- 支持完整 IANA 时区列表查询
- 输入时间戳 + 目标时区 → 当地时间

### 时长计算
- 两个 Unix 时间戳 → 精确时长
- 输出：总秒数、天/时/分/秒分解、人类可读字符串

### 当前时间
- 一键获取当前 Unix 时间戳（秒 + 毫秒）
- 同时展示所有格式的当前时间

## MVP 范围

- Unix → ISO 8601 / RFC 2822 / RFC 3339 / 自定义格式
- ISO 8601 → Unix
- 16 个常用时区转换
- 时长计算
- 当前时间按钮
- 一键复制
- 中英文界面

## 非目标

- 不提供历史时区规则变更（DST 转换按当前偏移量）
- 不提供日历视图或日期选择器
- 不存储或同步用户的时间戳历史
- 不包含 NTP 时间同步
- 不提供 cron 表达式解析

## 隐私模式

默认 **完全本地**：所有时间戳转换、格式化、时区查询均在浏览器 WASM 中完成。零网络请求。不收集任何数据。

## 验收标准

- 所有格式输出正确且与标准一致
- ISO 8601 解析支持多种常见格式
- 时区转换偏移量计算正确
- 毫秒/秒自动识别准确
- 时长计算结果精确
- 复制按钮功能正常
- WASM 文件大小 < 500KB（gzip 后 < 150KB）
- 页面首次加载时间 < 2 秒
